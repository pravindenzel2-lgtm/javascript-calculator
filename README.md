# JavaScript Calculator

## Description
An interactive command-line calculator built with JavaScript and Node.js.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Calculation history
- Division-by-zero protection
- Interactive menu

## Technologies
- JavaScript
- Node.js
- @inquirer/prompts
- Node.js built-in testing tools

## Installation
Run:

npm install

## Running the calculator
Run:

node index.js

## Running tests
Run:

npm test
